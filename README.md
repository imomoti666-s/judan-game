# 獣弾 -JUDAN-

太めで温厚な猪獣人を一体の愛機として育てる、スマートフォン縦画面固定の2D弾幕ハクスラです。敵と敵弾はCanvasの図形描画、自機と自弾は画像生成によるオリジナルスプライトを使用しています。

## v0.3.0で遊べる内容

- スマホの相対ドラッグ移動とPCのWASD／方向キー操作
- ホームでは正面、戦闘では敵を向く背面視点に分けた自機表示
- 戦闘時の静止・上・下・左・右・集中の6状態、各6コマの全身アニメ
- 端末サイズに追従する正しい9:16表示と、存在感を増した大型の自機表示
- 通常・集中を問わない自機の半透明化と、実判定に一致する赤い当たり判定点
- 移動速度を変えず、広域制圧の「通常射撃」と正面火力・貫通重視の「集中射撃」をタップで切替
- 常時一つ選ぶ「構え」4種。静止防御、通常連射、かすり炉心、前進強化から戦い方を決められる
- 主砲を大きく改造する「牙紋」12種・2枠。重量弾、速射、残像、瀕死強化、不発蓄力などを自由に重ねられる
- 随伴器を改造する「付随刻印」12種・2枠。陣形・射撃モード共鳴・炎上・鈍化・爆発・貫通・弾消し・炉心変換に対応
- 通常装備とは独立したドロップ品「随伴器」と専用装着枠
- 基本の双牙弾を残したまま、五方向散弾・大型貫通杭・追尾牙弾・左右随伴砲の4系統の副砲を追加
- 追尾牙弾は命中率重視の低火力型とし、主砲や他の副砲を食わない役割別バランス
- 随伴器のレアリティ別出力、12枠の専用所持欄、接続・解除・分解
- 自動射撃、通常／集中切替、かすり、炉心開放、ボム
- 4種の通常敵と三段階に変化するボス弾幕
- 危険度の異なる3ステージ
- 牙砲・護帯・霊具のランダム戦利品
- 粗製／加工／秘造／遺物／厄物の5段階レアリティ
- 装備、分解、恒久鍛錬、レベル、ローカル保存
- PWA、縦画面固定、セーブデータの書き出し／読み込み

## 操作

### スマートフォン

- 画面内ドラッグ：相対移動
- `通常／集中`をタップ：射撃モード切替（移動速度は共通）
- `霊圧`：敵弾消去と全体攻撃

### PC

- WASD／方向キー：移動
- Shift：通常／集中射撃を切替
- Space：霊圧
- Esc：一時停止

## ローカル起動

```bash
npm run serve
```

ブラウザで `http://localhost:4173` を開いてください。

## 検査

```bash
npm run check
```
