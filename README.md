# 獣弾 -JUDAN-

太めで温厚な猪獣人を一体の愛機として育てる、スマートフォン縦画面固定の2D弾幕ハクスラです。敵と敵弾はCanvasの図形描画、自機と自弾は画像生成によるオリジナルスプライトを使用しています。

## v0.2.1で遊べる内容

- スマホの相対ドラッグ移動とPCのWASD／方向キー操作
- ホームでは正面、戦闘では敵を向く背面視点に分けた自機表示
- 戦闘時の静止・上・下・左・右・低速の6状態、各6コマの全身アニメ
- 端末サイズに追従する正しい9:16表示と、存在感を増した大型の自機表示
- 高速・低速を問わない自機の半透明化と、実判定に一致する赤い当たり判定点
- 通常装備とは独立したドロップ品「随伴器」と専用装着枠
- 基本の双牙弾を残したまま、五方向散弾・大型貫通杭・追尾牙弾・左右随伴砲の4系統の副砲を追加
- 追尾牙弾は命中率重視の低火力型とし、主砲や他の副砲を食わない役割別バランス
- 随伴器のレアリティ別出力、12枠の専用所持欄、接続・解除・分解
- 自動射撃、低速移動、かすり、炉心開放、ボム
- 4種の通常敵と三段階に変化するボス弾幕
- 危険度の異なる3ステージ
- 牙砲・護帯・霊具のランダム戦利品
- 粗製／加工／秘造／遺物／厄物の5段階レアリティ
- 装備、分解、恒久鍛錬、レベル、ローカル保存
- PWA、縦画面固定、セーブデータの書き出し／読み込み

## 操作

### スマートフォン

- 画面内ドラッグ：相対移動
- `低速`長押し：精密移動・かすり範囲表示・集中射撃
- `霊圧`：敵弾消去と全体攻撃

### PC

- WASD／方向キー：移動
- Shift：低速
- Space：霊圧
- Esc：一時停止

## ローカル起動

```bash
npm run serve
```

ブラウザで `http://localhost:4173` を開いてください。

## 検査

```bash
npm run check
```
